Filler: A game about claiming all the boxes.

This game is inspired by the GamePigeon game for the iPhone, Filler

The objective for the game is simple, have the most squares claimed by the end of the game compared to your opponent. Each game starts with a randomly generated grid of colored squares, and each player starts by owning one square at opposite corners. To claim a square, you choose a color from the selection and any tile of that color you are touching becomes yours. You can't claim a color your or the opponent have claimed but once you claim a new color, the old color gets freed for either of you to claim again. Every time you switch to a new color, all of your owned tiles change color as well, so a player begins to branch out as the game goes on.
